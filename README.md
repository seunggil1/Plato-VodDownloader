# Plato-VodDownloader

## 1. Plato vod Downloader
### Plato 녹화 강의 동영상 다운로드 프로그램(Zoom 강의는 불가능합니다.)
#### Lastest version 1.094
#### How to use
1. 크롬 최신 버전 설치(현재 110버전까지 지원)
2. platoDownloadVod.exe 실행
3. 지시에 따라 다운로드 진행
4. Download 폴더에 해당 강의가 저장됨.

#### Warning
1. 온라인 출석부에서 해당 강의 열람 횟수+1 됩니다.
2. Plato에서 재생 중인 모든 강의를 종료하고 사용해야 됩니다.(중복 재생 방지로 인해 오류가 발생합니다)
